# pyro_example

A minimal Flame game made with Pyro. It loads one Scene, built from one Behavior and one Custom
component, through the generated Registry. It is a sample, not a published package.

Three things use it (spec 005):

- **The vertical slice.** `apps/editor/bin/play.dart` runs it and Hot-swaps the Scene when it is
  saved.
- **The CI contract test** (*Q59*). CI regenerates its Registry and Manifest, compares them with
  the committed files and the golden, and loads every Scene with the real Registry.
- **The README recipe's reference** for adding Pyro to a game.

## What's in it

| Path | What |
|---|---|
| `lib/behaviors/spin.dart` | `Spin`, a Behavior that turns its entity (`turnsPerSecond`, `clockwise`) |
| `lib/components/banner.dart` | `Banner`, a Custom component that shows text (`message`, `color`) |
| `assets/scenes/level1.scene.json` | the Scene: a spinning ship with a sprite and a hitbox, and a banner |
| `lib/example_game.dart` | loads the Scene and shows a HUD outside it: `time`, Hot-swap count, `code` |
| `lib/pyro.g.dart`, `lib/pyro.manifest.json` | generated by `pyro_generator`, committed |
| `test/goldens/pyro.manifest.json.golden` | the reviewed Manifest the contract test compares with |

It has a macOS runner only.

## Run it

From the repository root, `dart pub get`, then:

```bash
cd example
flutter run -d macos
```

To run it through Pyro's Play client, with Hot-swap on save:

```bash
cd apps/editor
dart run bin/play.dart ../../example
```

In a debug build the Runtime prints one line per load and Hot-swap: `[pyro] Scene loaded: <path>`,
`[pyro] Scene reloaded: <path>`, or `[pyro] Scene not reloaded: <path>: <reason>`. Pyro reads them to
know a Hot-swap reached the game.

## Regenerate

After changing an annotated class:

```bash
dart run build_runner build -d
```

Commit `lib/pyro.g.dart` and `lib/pyro.manifest.json`; CI fails if they are stale.

## Update the golden

When a Manifest change is intended, review it, then:

```bash
cp lib/pyro.manifest.json test/goldens/pyro.manifest.json.golden
```
